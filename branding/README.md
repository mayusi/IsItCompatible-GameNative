# GameNative IIC — Brand Assets

These are original marks for the **GameNative IIC** fork. Teal→violet distinguishes it from upstream's blue.

## Assets

| File | Dimensions | Purpose |
|------|-----------|---------|
| `emblem.svg` / `emblem.png` | 512 × 512 | App icon, favicon, avatar |
| `wordmark.svg` / `wordmark.png` | 1200 × 320 | Horizontal lockup for docs/READMEs |
| `banner.svg` / `banner.png` | 1280 × 420 | GitHub repo social banner |

## Palette

| Role | Hex |

| Gradient end (violet) | `#7c3aed` |

| Light foreground text | `#f8fafc` |
| Muted / tagline text | `#94a3b8` |

## Emblem concept

Rounded-square badge filled with the teal→violet gradient. The glyph is a game-controller silhouette whose center cutout forms a bold checkmark — reading simultaneously as "controller" (gaming) and "✓" (compatible). The D-pad and button cluster reinforce the gaming context; the checkmark is the "Is It Compatible?" answer.

## Usage

- Use `emblem.svg` wherever a square app mark is needed.
- Use `wordmark.svg` in README headers and documentation pages.
- Use `banner.svg` as the GitHub repository Open Graph / social preview image (Settings → Social preview).
- Do **not** stretch or recolor — the teal→violet gradient is the primary differentiator from upstream GameNative (which uses blue).
